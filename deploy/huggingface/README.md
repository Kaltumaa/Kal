# Mkulima Hub (public demo)

Climate-smart advisory co-pilot for the Dagoretti South extension desk. Source code, setup and docs:
https://github.com/Kaltumaa/Kal

This Space runs the same app as `make run`, with open-weights models (Qwen 2.5 3B and Moondream) on the Space's CPU.
All data is synthetic. Agent runs are slower here than on a laptop: allow 1–3 minutes per household.
